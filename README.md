# Homazi Design Website

静态展示网站，托管于 GitHub Pages。

## 在线访问

https://hormaz-su.github.io/homazi-design-website/

## 本地预览

```bash
cd website
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 目录结构

```
.
├── index.html
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── images/
```

## 部署

推送到 `main` 分支后，GitHub Pages 自动从根目录发布。
